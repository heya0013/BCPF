AI 应用场景 AI Application Scenarios

Demand Sensing + 供给协同（One Plan 输入增强） Demand Sensing + Supply Collaboration (One Plan Input Enhancement)

引入更多信号（POS、促销、天气、社交舆情），AI 优化预测输入，增强主计划（One Plan）的准确性与鲁棒性。 Introduce more signals (POS, promotions, weather, social sentiment), AI optimizes forecast inputs, enhancing the accuracy and robustness of the master plan (One Plan).

约束求解 + 情景规划 Constraint Solving + Scenario Planning

在 Supply Planning 层面做利润 / 服务 / 现金占用多目标情景规划，并基于约束求解推荐最优计划。 Conduct multi-objective scenario planning (profit / service / cash occupancy) at the Supply Planning level, and recommend optimal plans based on constraint solving.

异常检测 + 根因解释 + 行动推荐 Anomaly Detection + Root Cause Explanation + Action Recommendation

计划偏差、供应中断、需求异常时触发 root-cause 分析 + AI Agent 推荐修正动作。 Trigger root-cause analysis + AI Agent recommended corrective actions when planning deviations, supply disruptions, or demand anomalies occur.

规则 + ML 结合的分配优化 Rule + ML Integrated Allocation Optimization

在资源有限的条件下，使用规则与 ML 混合模型进行产能 / 物料 / 运输 分配优化。 Under limited resource conditions, use rule and ML hybrid models for capacity / material / transportation allocation optimization.

效果分析（机制视角） Effect Analysis (Mechanism Perspective)

Demand Sensing 提升预测信号质量，减少偏差；情景规划 + 约束求解强化计划稳定性；异常检测 + 行动推荐及时纠偏；规则 + ML 分配确保资源在复杂条件下最优使用。 Demand Sensing improves forecast signal quality and reduces deviations; scenario planning + constraint solving enhances planning stability; anomaly detection + action recommendation enables timely correction; rule + ML allocation ensures optimal resource utilization under complex conditions.
