AI 应用场景 AI Application Scenarios

可售口径与策略引擎 Sellable Caliber & Strategy Engine

统一定义 ATS 口径（含在途、保留、被占用、店内可售），在分配引擎中按优先级与规则计算实时 ATS。 Unify the definition of ATS caliber (including in-transit, reserved, occupied, in-store sellable), and calculate real-time ATS in the allocation engine according to priorities and rules.

短期到货预测 + 动态 ATS Short-Term Arrival Prediction + Dynamic ATS

结合 ETA / 运输数据与 ML 模型预测短期到货，动态调整承诺窗口。 Combine ETA/transportation data with ML models to predict short-term arrivals and dynamically adjust commitment windows.

事件驱动集成（CDC） Event-Driven Integration (CDC)

CDC 实时捕获变更并触发规则引擎，保证多系统 ATS 一致。 CDC captures changes in real time and triggers the rule engine to ensure ATS consistency across multiple systems.

可解释看板 + 行动建议 Interpretable Dashboard + Action Recommendations

XAI 解释 ATS 变化，推送补货/调拨建议，实现“建议 - 采纳 - 反馈”闭环。 XAI explains ATS changes, pushes replenishment/transfer recommendations, and realizes a "recommendation-adoption-feedback" closed loop.

AI 应用场景效果分析 Effect Analysis of AI Application Scenarios

通过 item-level 可见性和 ETA 预测，承诺口径一致性显著提升，减少人工校正与改期；CDC 实时集成降低二次改配；XAI 看板改善争议关闭周期和客户体验。 Through item-level visibility and ETA prediction, the consistency of commitment caliber is significantly improved, reducing manual correction and rescheduling; real-time CDC integration reduces secondary reallocation; XAI dashboard improves dispute closure cycle and customer experience.

Inditex / Zara：RFID 提升库存可见性 Inditex / Zara: RFID Enhances Inventory Visibility

Inditex 自 2014 年起在 Zara 门店和 DC 铺设 RFID，提高了库存可见性与补货速度，为准确 ATS 和实时承诺提供数据支撑。 Since 2014, Inditex has deployed RFID in Zara stores and DCs, improving inventory visibility and replenishment speed, and providing data support for accurate ATS and real-time commitments.

小结：Item-level 可见性是高准确度 ATS 的前提，随后结合 ETA、规则引擎与 XAI 才能全面放量。 Summary: Item-level visibility is a prerequisite for high-accuracy ATS; subsequent integration with ETA, rule engines, and XAI is required to achieve full-scale application.
